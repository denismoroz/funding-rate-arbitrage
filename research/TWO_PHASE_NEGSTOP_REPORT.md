# Вариант A — Phase-1 negative hard-stop (обход min_hold)

**Дата:** 2026-06-08
**Скрипт:** [two_phase_negstop.py](two_phase_negstop.py) · **Данные:** [two_phase_negstop_results.csv](two_phase_negstop_results.csv)
**Набор:** прод 7 коинов (BTC ETH SOL HYPE ZEC PURR XPL), K=3, данные до 2026-05-12.

## Что проверяли

Идея: «фандинг ушёл в минус → руби», ОБХОДЯ динамический min_hold. Baseline = точная
прод-логика (динамический min_hold cap=720, phase1 consec>72, phase2 < −0.10).
Вариант A: в Phase 1, если сглаженный сигнал < `thr` И `consec_negative ≥ pat` →
закрыть немедленно, **игнорируя min_hold**. Контроль — то же без bypass.

`bleed_h` = суммарные часы, проведённые открытым в Phase 1 при rate < −0.10 (прямая
мера «кровотечения», в которое попал SOL #26).

## Выводы

1. **Bypass — это ключ.** Контроль без обхода min_hold почти не отличается от baseline
   (negstop сработал лишь 4 раза, bleed_h 2811): правило «режь по негативу» **бесполезно,
   пока его душит min_hold**. Именно обход замка даёт эффект — ровно патология SOL #26.

2. **Эффект — риск, а не доходность.** Годовая почти не меняется (10.41 → 10.5%, в пределах
   шума, местами чуть выше). Зато при `thr=−0.20`: **maxDD вдвое меньше** (0.47→0.21%),
   **Calmar ×2.2** (22→50), часы «кровотечения» урезаны в 3.5 раза (2838→806). Это именно
   то, чего хотели: перестать сидеть в убыточной позиции, не теряя в общем PnL.

3. **Не переусердствовать.** Агрессивные пороги (thr=−0.05, pat=6) режут позиции, которые
   ещё отбились бы → доходность last_90d падает (4.10 vs 5.52) и растёт churn fees.
   Sweet spot — **резать только при решительно глубоком негативе, выдержанном 6-12 ч**.

## Рекомендация

`neg_stop_threshold = −0.20`, `neg_stop_patience = 6…12 ч`, `bypass_min_hold = True`,
только в Phase 1. Профиль доходность-нейтральный, риск вдвое ниже. Реализация в прод-коде
([two_phase_signals.py](../src/frab/engine/two_phase_signals.py) + [exit.py](../src/frab/strategy/two_phase/evaluators/exit.py)) — отдельным шагом по запросу.
