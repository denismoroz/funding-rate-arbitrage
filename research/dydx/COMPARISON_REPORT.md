## Что торгуется на dYdX

Все 7 монет нашего universe присутствуют на dYdX v4 в статусе ACTIVE:
`BTC`, `ETH`, `SOL`, `HYPE`, `AVAX`, `LINK`, `DOGE`

**Ограничения по истории:**
- BTC/ETH/SOL/AVAX/LINK/DOGE: данные с **~2023-10-27** (dYdX v4 mainnet launch)
  → hot-окно фактически сокращено до 14 мес (окт 2023 – дек 2024) вместо 19 мес
- HYPE: данные только с **2026-02-26**, hot-окно отсутствует полностью
- Cold-окно (2025-01-01 → 2026-04-01) для всех монет кроме HYPE покрыто полностью

## Почему HL доминирует в cold-режиме

Отрыв HL в cold-режиме объясняется структурными отличиями:

1. **HL фокус на retail perp-трейдинге** — HL создавался как perp-биржа с высоким retail интересом, что создаёт устойчивое contango давление
2. **dYdX — on-chain (Cosmos)** — меньший retail поток, институциональные арбитражёры быстро компрессируют funding к нулю
3. **SOL cold = −1.83% на dYdX** — фактически негативный (шорты *платят* лонгам в среднем), это разрушительно для стратегии long-spot + short-perp

## Технические характеристики для live-интеграции

| Параметр        | dYdX v4                           |
|-----------------|-----------------------------------|
| API             | Публичный indexer, без ключей     |
| Торговля        | Cosmos chain, нужен кошелёк DYDX  |
| Fees (maker)    | −0.01% (rebate!)                  |
| Fees (taker)    | +0.05%                            |
| Min order       | Нет явного минимума               |
| Liquidation     | Стандартная perp модель           |
| Cross-margin    | Поддерживается                    |

**Blocкер для live:** Торговля на dYdX v4 требует Cosmos wallet (dYdX chain), что несовместимо с текущим HL-focused executor. Интеграция потребует отдельного dYdX SDK и кошелька.

---

## Итоговый вывод: стоит ли интегрировать dYdX?

**Нет — не приоритетно.** Основания:

1. **Funding edge ниже HL** в cold-режиме (2025–2026) на 4-9% APR по большинству монет — именно это period релевантен для текущего live-трейдинга
2. **SOL cold отрицательный** (−1.83%) на dYdX делает стратегию убыточной для этой монеты
3. **LINK cold 1.99%** vs HL 11.21% — огромный разрыв
4. **Интеграционный cost** высокий: Cosmos chain, новый wallet, отдельный executor модуль
5. **HYPE** — единственная монета где dYdX cold лучше HL, но это значит лонги платят больше шортерам на dYdX, что противоречит нашей стратегии (мы шортим perp)

**Потенциальное применение (если есть ресурсы):** Cross-exchange funding rate divergence: если dYdX и HL расходятся достаточно, можно держать long spot + short dYdX perp vs short HL spot + long HL perp. Но это требует значительно более сложной инфраструктуры.

**Рекомендация:** Продолжать фокус на Hyperliquid как основной площадке. dYdX исследование закрыть как "evaluated, not prioritized".
